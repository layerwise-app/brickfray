# Announcer voice credits

The multi-kill announcer is one voice: cmesias' "Multikill Voice SFX" pack, released under CC0 1.0 (the itch.io page's licensing line reads "Creative Commons — CC0 1.0 Universal"; the pack's README.txt reads "This work is licensed under a Creative Commons 0 (CC0) License"). Each line is the pack's recording trimmed to the speech and its tail (80 ms fade out), set to a -1 dBFS peak and encoded as 48 kHz mono MP3; the five-kill line joins two of the pack's recordings (below). The pack has no line for six kills (its six-kill word is not "Hexa"), so the top tier is a wordless brass sting made from VSCO 2 Community Edition samples (Versilian Studios, CC0 1.0). The game matches its loudness when it loads the lines.
