# Announcer voice credits

The multi-kill announcer is one voice: cmesias' "Multikill Voice SFX" pack, released under CC0 1.0 (the itch.io page's licensing line reads "Creative Commons — CC0 1.0 Universal"; the pack's README.txt reads "This work is licensed under a Creative Commons 0 (CC0) License"). Each file is the pack's recording trimmed to the speech and its tail (80 ms fade out), set to a -1 dBFS peak and encoded as 48 kHz mono MP3; nothing else is changed. The game matches its loudness when it loads the lines.
